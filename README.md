# কামারপাড়া স্কুল অ্যান্ড কলেজ সুবর্ণ জয়ন্তী ও প্রাক্তন শিক্ষার্থী পুনর্মিলনী
### Golden Jubilee & Alumni Reunion - Kamarpara School & College

বিদ্যালয়ের সুবর্ণ জয়ন্তী ও ৫০ বছর পূর্তি উপলক্ষে একটি আধুনিক, রেসপন্সিভ ইভেন্ট ম্যানেজমেন্ট, অ্যালামনাই অনলাইন রেজিস্ট্রেশন ও ই-ব্যাজ জেনারেটর ওয়েব অ্যাপ্লিকেশন।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **বর্ণাঢ্য ল্যান্ডিং পেজ**:
   - ৫০ বছর পূর্তির উৎসবমুখর থিম ও বাংলা ফন্ট (*Hind Siliguri*)।
   - ২২ ও ২৩ জানুয়ারি মহোৎসবের লাইভ অ্যানিমেটেড **কাউন্টডাউন টাইমার**।
   - নোটিশ বোর্ড (রেজিস্ট্রেশনের সময়সীমা, ফি বিবরণ ও মিটিং সূচি)।
   - **ব্যাচ সমন্বয়কদের তালিকা ও সার্চ ডিরেক্টরি** (১৯৮৭ থেকে ২০১৮ ব্যাচ পর্যন্ত সকল সমন্বয়কের নাম ও যোগাযোগ)।

2. **অ্যালামনাই অনলাইন রেজিস্ট্রেশন ফরম**:
   - বাংলা ও ইংরেজিতে নাম, এসএসসি ব্যাচ (১৯৭০-২০২৬), মোবাইল নম্বর, ইমেইল, পেশা ও বর্তমান ঠিকানা।
   - অফিসিয়াল টি-শার্ট সাইজ নির্বাচন (S, M, L, XL, XXL) ও প্রোফাইল ফটো প্রিভিউ।
   - **ডায়নামিক ফি ক্যালকুলেটর**: মূল ফি ১,০০০ টাকা + অতিরিক্ত প্রতি পরিবার সদস্য/অতিথির জন্য ৫০০ টাকা।
   - বিকাশ / নগদ / রকেট পেমেন্ট ট্রানজেকশন আইডি (TrxID) ও নম্বর ইনপুট।

3. **প্রিন্টযোগ্য ই-ব্যাজ ও রেজিস্ট্রেশন স্লিপ (ID Badge)**:
   - ইউনিক রেজিস্ট্রেশন আইডি (যেমন: `SJ-2026-1001`)।
   - ভেরিফিকেশনের জন্য **ডায়নামিক QR Code** (গেট এন্ট্রির জন্য)।
   - পেমেন্ট ভেরিফিকেশন স্ট্যাটাস (`Verified` / `Pending`)।
   - ব্রাউজার থেকে সরাসরি **প্রিন্ট বা PDF সেভ** করার সুবিধা।
   - মোবাইল নম্বর দিয়ে হারিয়ে যাওয়া স্লিপ পুনরায় খোঁজার সার্চ পেজ।

4. **সুরক্ষিত অ্যাডমিন কন্ট্রোল প্যানেল**:
   - পাসকোড প্রোটেকশন (ডিফল্ট পিন: `2026`)।
   - মোট রেজিস্ট্রেশন, মোট সংগৃহীত তহবিল এবং অনুমোদিত পেমেন্টের পরিসংখ্যান।
   - ডাটা টেবিল থেকে ফিল্টার ও এক ক্লিকেই পেমেন্ট অনুমোদন (Verify)।
   - এক ক্লিকে সকল রেজিস্ট্রেশন ডাটা **Excel / CSV এক্সপোর্ট**।

5. **স্ট্যান্ডঅ্যালোন `index.html`**:
   - কোনো সার্ভার বা নোড ইন্সটল ছাড়াই যেকোনো ব্রাউজারে সরাসরি ডাবল-ক্লিকে চালানোর উপযোগী সিঙ্গেল-ফাইল ভার্সন।

## 🚀 কীভাবে রান করবেন (How to Run Locally)

### অপশন ১: সরাসরি HTML ফাইল
ব্রাউজারে সরাসরি `index.html` ফাইলটি ডাবল ক্লিক করে চালু করুন।

### অপশন ২: Next.js ডেভেলপমেন্ট সার্ভার
```bash
# ডিপেন্ডেন্সি ইন্সটল
npm install

# ডেভেলপমেন্ট সার্ভার রান
npm run dev

# প্রোডাকশন বিল্ড
npm run build
npm run start
```
ব্রাউজারে ভিজিট করুন: `http://localhost:3000`
